# Drawer Lock System Research

Structured research project to select and implement electronic locking mechanisms for two drawers in a professional closet system (Sammamish, WA).

## Goal

Choose the best acquisition path — purpose-built product, retrofit smart lock hardware, or custom DIY build — for independently locking two 30"-wide drawers with fingerprint + Bluetooth access, covert appearance, and mandatory backup access.

## Constraints

- Each drawer locks and unlocks independently
- Must look completely normal when locked — no visible hardware
- Primary access: fingerprint reader (mounted on side panel), Bluetooth/app
- Mandatory backup: key, PIN, or battery backup if primary fails
- Four-sided enclosure — adjacent drawers can't be used to defeat the catch
- Budget: $1,200 total for both drawers
